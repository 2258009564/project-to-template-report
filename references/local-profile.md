# Local profile lookup

Resolve the local root from CODEX_HOME, otherwise the current user's ~/.codex. Profile records are timestamped notes under <local root>/memories/extensions/ad_hoc/notes/ with marker `word-report-profile-v1`. Read only matching records before asking identity questions. If missing, inspect user-supplied prior documents before asking.

Reuse consistent sourced facts without repeated confirmation. Record field, value, source, date and evidence. Distinguish the user from teammates; first position in a group document does not establish identity. Current explicit information overrides older records. Teachers, dates, courses and teammates are task-specific. Resolve conflicting sources before asking only for unresolved fields.

For ongoing authorized personalization, follow [local learning](local-learning.md). Keep all personal values outside the skill and deliverables; append correction notes instead of editing historical records. Do not store credentials, signatures or unrelated document contents.

## Mandatory identity gate

Before generating or editing the report, identify the personal fields required by its template (for example name, student ID, class, university and major). Check current instructions, relevant local records and user-supplied materials first. If any required personal value is still unknown, ambiguous or conflicting, stop report work, ask only for those unresolved fields together, and wait for the user response. A missing profile file is not itself a blocker when supplied materials resolve the fields. Do not default required personal fields to blank, invent values, infer identity from teammates, or deliver while the question is unanswered. Only explicit user instructions to omit or leave particular fields blank waive those fields; unrelated missing dates and teacher metadata are not personal profile defaults.

When a user supplies missing personal information, use it for this report. If ongoing local memory is already authorized, append the confirmed reusable fields with source and date before resuming, then read them on later relevant tasks. Otherwise include a short local-memory consent question with the missing-field question; saving is optional and declining it must not prevent report completion. Do not interpret a report request alone as consent to persist. Store no task-specific teacher, date or teammate information as a reusable identity default.
