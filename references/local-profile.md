# Local profile lookup

Resolve the local root from CODEX_HOME, otherwise the current user's ~/.codex. Profile records are timestamped notes under <local root>/memories/extensions/ad_hoc/notes/ with marker `word-report-profile-v1`. Read only matching records before asking identity questions. If missing, inspect user-supplied prior documents before asking.

Reuse consistent sourced facts without repeated confirmation. Record field, value, source, date and evidence. Distinguish the user from teammates; first position in a group document does not establish identity. Current explicit information overrides older records. Teachers, dates, courses and teammates are task-specific. Resolve conflicting sources before asking only for unresolved fields.

For ongoing authorized personalization, follow [local learning](local-learning.md). Keep all personal values outside the skill and deliverables; append correction notes instead of editing historical records. Do not store credentials, signatures or unrelated document contents.
